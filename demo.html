M-SAgent

MLLM + SAM3 智能图像分割系统 —— 让 AI "看懂你说的"，然后精准把它框出来

你给一张图片，说一句话（比如 "穿红衣服的女孩"），
系统自动理解你的意思，在图片里精准找到并标出对应的区域。

两大核心模型

🧠

Qwen2.5-VL (MLLM)

多模态大语言模型 —— "大脑"

  • 能同时"看"图片 + "读"文字
  • 理解用户的自然语言描述
  • 分析图像内容，做出策略决策
  • 选择使用哪个工具、传什么参数
  • 最后还负责评估结果好不好
✂️

SAM3

分割大模型 —— "手"

  • 专门做图像分割（把目标"抠"出来）
  • 支持文本提示：给一个词，分割对应物体
  • 支持点提示：给几个坐标点，分割该区域
  • 输出 Mask（蒙版）+ 置信度分数
  • 运行在 GPU 上，平时存在 CPU 省显存

三大工具详解

MLLM 分析图片后，会选择最合适的工具来执行分割。每个工具有不同的策略：

💡

ConceptGenerator

概念生成器 —— 把你说的话拆成多个"关键词概念"。

比如你说"穿红衣服的女孩"，它可能生成 "red jersey"、"girl"、"red clothing" 等概念， 然后逐个让 SAM3 用每个概念进行文本分割，最后选分数最高的那个。

文本提示分割
📍

ObjectLocator

目标定位器 —— 在图片上标出"点"来告诉 SAM3 去哪里切割。

MLLM 看带网格的图片，选出目标所在的网格坐标， 转换成像素坐标后作为"点提示"给 SAM3。
还会优先尝试 TrainAdapter 服务获取更准确的定位。

点提示分割
🔍

ImageEnhancer

图像增强器 —— 目标太小看不清？先放大再分割！

MLLM 指定图片中某个矩形区域（网格坐标）， 系统把这块区域裁剪出来并放大到 1024px， SAM3 在放大图上分割，最后再把 Mask 缩小还原到原图坐标。

局部放大 + 还原
❌

report_no_mask

放弃报告 —— 如果 MLLM 认为图片中根本没有你描述的东西， 就直接报告"未找到匹配内容"，结束流程。

终止信号

完整工作流程

1

加载图片 + 预处理

读取你给的图片，转成 RGB 格式，缩放到最大 1024px。
同时给图片画上 5x5 网格（带坐标数字），方便 MLLM 精准描述位置。

2

MLLM 分析 + 决策

把原图和带网格的图一起发给 Qwen2.5-VL，连同你的文字描述。
MLLM 会按 4 步思考：
  1. 分析图片内容
  2. 思考要找什么
  3. 复习工具规则
  4. 选择工具 + 参数
输出格式：<tool>{"name": "xxx", "parameters": {...}}</tool>

3

执行工具（三选一）

根据 MLLM 的选择，调用对应的工具：
concept_generator → 生成多个概念词 → SAM3 文本分割
object_locator → 定位坐标点 → SAM3 点分割
image_enhancer → 裁剪放大 → SAM3 分割 → Mask 还原

4

SAM3 分割 + 生成 Mask

SAM3 从 CPU 移到 GPU，执行分割，输出多个候选 Mask 和置信度分数。
选出分数最高的那个 Mask，叠加到原图上生成可视化检查图。

5

MLLM 评估结果

把原图和叠加了 Mask 的图再次发给 MLLM。
MLLM 判断：这个分割结果对不对？
输出 <verdict>Accept</verdict> 或 <verdict>Reject</verdict>
如果 Reject，还会指出哪些 Mask 该删掉。

6

循环还是结束？

Accept → 保留所有 Mask，流程结束
Reject → 删掉不好的 Mask，回到第 2 步，MLLM 重新决策
最多循环 5 次（可配置）

7

输出最终结果

把所有被接受的 Mask 合成到原图上（不带编号），保存为 JPG。
同时保存 Mask 的 numpy 数组 (.npy)，方便后续程序使用。

关键设计亮点

Agent 式循环

MLLM 不是跑一次就结束，而是像一个 Agent 一样持续决策 → 执行 → 评估 → 调整，直到满意为止。最多 5 轮迭代。

高分辨率策略

图片太小？自动放大到 300 万像素以上再给 MLLM 看，确保 MLLM 看得清细节。所有尺寸对齐到 28 的倍数（Qwen2.5-VL 要求）。

GPU 显存管理

SAM3 平时存在 CPU，需要分割时才移到 GPU，用完立刻释放。避免和 MLLM 抢显存。

多源定位（TrainAdapter）

ObjectLocator 优先通过 TrainAdapter 外部服务定位目标。如果服务不可用或置信度低，才回退到 MLLM 的网格坐标方案。

Mask 累积与筛选

每轮新 Mask 会和之前已接受的 Mask 合并展示。MLLM 评估时可以选择性拒绝其中某些编号的 Mask，实现精细控制。

完整中间记录

每个工具调用的中间结果（裁剪图、点可视化、Mask 叠加图、元数据 JSON）全部保存到 tool_calls_log，方便调试和复盘。
